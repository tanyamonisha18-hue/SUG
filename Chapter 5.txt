# Chapter 5: Creating and Managing Playlists

## What Is a Playlist?

A playlist is a collection of songs that you choose. You can create playlists for different moods, activities, or types of music.

For example, you can create playlists for:

- Workout music
- Party music
- Relaxing music
- Road trips
- Study music

## Create a Playlist

Follow these steps to create a playlist:

1. Open Spotify.
2. Go to **Your Library**.
3. Select **Create Playlist**.
4. Enter a name for your playlist.
5. Select **Create**.

Your new playlist is now ready.

## Add Songs to a Playlist

You can add songs to your playlist at any time.

1. Search for a song.
2. Select the **More** option next to the song.
3. Select **Add to playlist**.
4. Select the playlist where you want to add the song.

## Remove a Song from a Playlist

If you no longer want a song in your playlist, you can remove it.

1. Open the playlist.
2. Find the song you want to remove.
3. Select the **More** option.
4. Select **Remove from this playlist**.

## Rename a Playlist

You can change the name of a playlist.

1. Open the playlist.
2. Select the **More** option.
3. Select **Edit playlist**.
4. Enter a new name.
5. Save the changes.

## Share a Playlist

You can share your playlist with other people.

1. Open the playlist.
2. Select the **More** option.
3. Select **Share**.
4. Choose how you want to share the playlist.
